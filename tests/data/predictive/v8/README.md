# Predictive benchmark v8

O v8 mede identidade semântica de causas e alvos, comparação par-a-par e
invariância a nomes. `holdout_v8` foi criado e selado antes de qualquer mudança
comportamental no seletor. Nomes e texto não fazem parte das assinaturas.

O conjunto contém 15 casos novos de desenvolvimento e 20 casos holdout em
domínios distintos. O holdout só pode ser executado live uma vez após o tuning.
