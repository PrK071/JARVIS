# F5-TTS pt-BR: licenças da prova local

Esta prova usa componentes com licenças diferentes:

- Código [SWivid/F5-TTS](https://github.com/SWivid/F5-TTS): MIT.
- Pesos [firstpixel/F5-TTS-pt-br](https://huggingface.co/firstpixel/F5-TTS-pt-br), revisão `5ebc6913f2d92e4c0cb5396a9867aa1c0c1c4281`: CC-BY-NC-4.0.
- Dataset de treinamento declarado [firstpixel/pt-br_char](https://huggingface.co/datasets/firstpixel/pt-br_char): CC-BY-SA-3.0; derivado de gravações Common Voice conforme o model card.
- Vocoder [charactr/vocos-mel-24khz](https://huggingface.co/charactr/vocos-mel-24khz): MIT.
- Referências humanas [Edresson/TTS-Portuguese-Corpus](https://github.com/Edresson/TTS-Portuguese-Corpus): CC BY 4.0; atribuição a Casanova et al., *TTS-Portuguese Corpus*.

O checkpoint F5 pt-BR é preliminar e não deve ser tratado como liberado para uso comercial ou distribuição. Esta avaliação foi limitada a uma prova local não comercial. Qualquer distribuição futura exige nova revisão das licenças, atribuições e fontes dos dados.

O corpus de referência contém fala humana brasileira de um locutor adulto. Os áudios, pesos e caminhos locais não são versionados.
